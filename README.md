# word-power

Interactive etymology atlas — word roots, IPA, morphology and Wiktionary links.

This repository is the GitHub Pages deployment target for
https://xyavecasdf.github.io/word-power/. The source of truth is
`XYavecasdf/XYavecasdf.github.io/word-power/`; the page and lexicon are
synced from that directory after validation.
